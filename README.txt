NFC DIGITAL PROFILE — VERSI PERTAMA

Isi paket:
- index.html: website satu halaman, tanpa database/backend.

CARA UJI DI LAPTOP
1. Ekstrak folder.
2. Buka index.html di browser.
3. Untuk melihat contoh, buka:
   index.html?wa=6281234567890&ig=contoh.akun&lat=-8.172&lng=113.701

FORMAT URL UNTUK NFC TOOLS
https://DOMAIN-KAMU/p?wa=6281234567890&ig=contoh.akun&lat=-8.172&lng=113.701

Parameter:
- wa  : nomor WhatsApp format internasional, angka saja (Indonesia diawali 62).
- ig  : username Instagram, tanpa @.
- lat : latitude lokasi.
- lng : longitude lokasi.

CATATAN
- NFC Tools > Write > Add a record > URL/URI, lalu masukkan seluruh URL dalam SATU BARIS.
- Website ini hanya menampilkan tombol untuk parameter yang valid dan tersedia.
- Hosting harus menggunakan HTTPS agar mudah dibuka dari HP.
- Data di query URL bersifat publik bagi siapa pun yang memindai tag.
- Uji panjang URL terhadap kapasitas tag sebelum membeli/menulis banyak tag.
